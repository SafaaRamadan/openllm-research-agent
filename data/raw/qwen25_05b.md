
# Qwen2.5-0.5B-Instruct

## Model identity
Qwen2.5-0.5B-Instruct is an instruction-tuned causal language model from the Qwen2.5 family.

## Model size
The official model card reports approximately 0.49 billion total parameters and 0.36 billion non-embedding parameters.

## Context length
The model card reports a full context length of 32,768 tokens and generation up to 8,192 tokens.

## Architecture
The model uses a Transformer architecture and includes components such as RoPE, SwiGLU, RMSNorm, and grouped-query attention.

The Hugging Face model page identifies the license as Apache-2.0. Check the official license and intended use before using the model in a specific product.
