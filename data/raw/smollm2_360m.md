
# SmolLM2-360M-Instruct

## Model identity
SmolLM2-360M-Instruct is an instruction-tuned compact language model published by Hugging Face.

## Model size
The model variant identifies a model with approximately 360 million parameters.

## Context length
The official model configuration specifies a maximum position length of 8,192 tokens.

## Architecture
The configuration identifies a Llama-style causal language model architecture.

## Intended use
The SmolLM2 family is designed to provide compact language models for a range of text tasks. Actual quality depends on the task, prompt, and evaluation method.

The official Hugging Face model page identifies the license as Apache-2.0. Review the model card and license before deployment.
